## Learnings

1. **tokio-vsock 0.4 API changed**: The `VsockListener::bind()` now takes `(cid: u32, port: u32)` instead of `VsockAddr`. Also requires `mut` for the listener. See `native/mjolnir_guest_agent/src/main.rs:43-45`.

2. **Hetzner Cloud VPS does not support nested virtualization**: Standard cloud VMs block KVM. Need either:
   - Hetzner dedicated server (bare metal)
   - GCP with `--enable-nested-virtualization`
   - Local Linux machine with VT-x/AMD-V enabled

3. **Guest agent builds successfully**: The musl-static binary is 1.5MB and works in minimal rootfs. Built on remote server at `/root/mjolnir/native/mjolnir_guest_agent/target/x86_64-unknown-linux-musl/release/mjolnir-agent`.

4. **Rootfs builds successfully**: 308MB Debian 12 Bookworm image with guest agent installed and enabled as systemd service. Built at `/root/mjolnir/debian-12.ext4` on the test server.
