## Required repair

### V1 / remaining N2 — P1: vectored writes bypass pending cancellation

`native/mjolnir_relay/src/edge_http.rs:296–305`, specifically the direct delegation at line 301.

`poll_write` now calls `ctx.aborted(cx)`, registering the HTTP task's waker on its pending tickets and refusing output after invalidation. `poll_write_vectored` does neither. `is_write_vectored` advertises the underlying socket's capability. Tokio TCP supports vectored writes; pinned Hyper 1.12.0 selects its Queue strategy when that capability is true and calls `poll_write_vectored` while draining buffered headers/body, before `poll_flush`. A blocked vectored write therefore cannot reach the new flush guard. The connection future itself does not independently observe pending cancellation.

**Independent reproduction:** `real_vectored_write_invalidation_defect` uses an actual ephemeral TLS MoQ relay, an established same-token incumbent, a real WHIP `Some(Response)`, and production `serve_connection`. Its controlled socket advertises vectored support and holds `poll_write_vectored` Pending. DELETE removes the candidate and unregisters the vendor Response. The HTTP task nevertheless fails to complete within 200 ms. Explicitly waking the captured socket waker still leaves it pending for another 200 ms. Counts remain the correct incumbent-only `sessions=1, runners=1, refs=1`; the test must externally abort the HTTP task. Passing this characterization test asserts the defect, not acceptance. This is deterministic socket backpressure at the real Hyper boundary, not a claim to have filled a kernel TCP buffer.

**Smallest fix:** apply the same pending-ticket cancellation registration/check in `poll_write_vectored` before delegating, returning `ConnectionAborted` when tripped. Alternatively, route all writes through the guarded scalar path by disabling vectored support. Keep the successful-underlying-flush acknowledgement boundary and pending-only cleanup unchanged. Add vectored held-write tests for deadline, DELETE, drain and relay death; require HTTP completion without external abortion and preservation of already acknowledged sessions where applicable. Do not rely solely on non-vectored doubles.
