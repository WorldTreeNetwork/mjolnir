## Nits (handle during `act`, not a re-advise)

1. **ADR number collision.** `docs/decisions/0004-web-pty-edge.md`
   is already Accepted (2026-08-18). This reopen reused `0004`.
   `docs/architecture.md:208` and `:693` now both say “ADR 0004”
   for different decisions. Renumber the hotel to **0005** and
   retarget the ADR 0002 pointer. Filename uniqueness is not
   enough; humans say the number.

2. **Decision 3 bullet order is invalid SQL.** `design.md:69–70`
   lists `CREATE DATABASE … OWNER` *before* `CREATE ROLE`.
   Postgres requires the role first. Swap the bullets when
   implementing; do not copy the list as a script.

3. **UFW/INPUT is unspecified.** Guest TCP to `10.200.0.1:5432`
   arrives on TAP and is **INPUT**, not FORWARD.
   `scripts/bootstrap-host-ubuntu.sh:965–971` only wires NAT +
   FORWARD for `10.200.0.0/10`. Default deny incoming will black
   hole the hotel even with a valid secret. Allow 5432 from the
   overlay CIDR on the dummy/`lo` address as part of the bootstrap
   box. Spec scenario “Guest with secret can migrate” will catch
   a miss; do not wait for production.

4. **Prefer dummy over `lo`.** `design.md:46` still says
   “dummy or `lo`” (the first advise’s words). Packets for an
   address on `lo` arriving on TAP can die on `rp_filter` /
   `accept_local`. Dummy is the topology that matches
   `docs/architecture.md:369–377` (TAP, no host IP, proxy ARP,
   `/32` guest, default via `eth0`). Pick dummy unless you prove
   `lo` in that path.

5. **`allocate_ip/1` must remap, not fail spawn.** A vm_id can
   hash to `10.200.0.1` today (`network.ex:150–178`). “Refuses”
   (`design.md:47`) must mean skip/rewrite to another address,
   not `{:error, …}` for that VM forever.

6. **Pin the `DATABASE_URL` string.**
   `postgres://<ident>:<pass>@10.200.0.1:5432/<ident>` (no Unix
   socket, no public NIC). `ensure/1` as specified takes an
   identifier; the declared list must carry `slug` so the JSON
   lands at `deploy/secrets/hypersigil-api.json`, not
   `hypersigil.json`. Name the list’s config key and the
   operator command during implement (`mj` subcommand is fine).

7. **Docs that this change makes false, still false:**
   `docs/security/host-hardening.md:67–70` (socket-only, derived
   data only); living spec purpose
   `openspec/specs/buzz-local-client/spec.md:13` (“catalog, not
   a tenant hotel”) — fold replaces the *requirement* block, not
   the purpose paragraph; `docs/guide/deploying-an-app.md:172`
   still shows `/var/lib/mjolnir/<app>-secrets.json`. Update on
   `act` / fold.

8. **`password_encryption = scram-sha-256`** in the clobbered
   `postgresql.conf` (`server.ex:237–256`). Ubuntu 24.04’s PG 16
   defaults to scram; pin it anyway so a major bump cannot store
   md5.

9. **MODIFIED “SHALL NOT reach the tenant TCP listener”**
   (`specs/buzz-local-client/spec.md:10–11`) is stronger than
   the overlay design. Postgres will handshake, then pg_hba/scram
   reject. That is correct. Do not implement a second firewall
   story that tries to make the SHALL literal unless you also
   change the unprovisioned scenario (it already says “rejects
   authentication”, `specs/host-postgres/spec.md:48–52`).

10. **`scripts/bootstrap-host-arch.sh`** is a twin of the Ubuntu
    bootstrap. Decision 2 names only Ubuntu + “the running host.”
    If an Arch host is still in play, assign `10.200.0.1` there
    too. If not, say so in the implement notes.
