## What both named

1. **Wake producer is unspecified.** Mentions live on Nostr. A dormant
   body cannot read Nostr. Nothing is assigned to turn a mention into an
   admitted wake. Either the journey's "mention → reply" assumes a live
   harness (no thaw), or some implicit bridge exists despite Decision 1.
   v1 posture must be written down: *live bodies answer mentions;
   dormant/stopped bodies do not, until an admitted control.*

2. **Enforcement is `deliver_message/3`, before queue.**
   `lib/mjolnir/vm.ex:784-807` restores on any dormant hit, no
   classification. Router-only admission loses vsock/MCP/internal
   callers. Queue-then-admit leaves denied junk in `pending_messages`
   for the next legitimate thaw (`queue_message` at 793, retry at
   `retry_deliver_message`).

3. **Dormant ≠ `:stopped` ≠ `:never`.** Reconcile already finalizes
   `:never` (`lib/mjolnir/reconcile.ex:169-170`). `deliver_message`
   only thaws `DormantRegistry`. A finalized body returns `:not_found`.
   I5 for Buzz is mostly the `:never` path, not dormancy. `signal_done`
   on a `:never` body is an unaddressed side door.

4. **identikey-protocol owns wire + pure validators, not lifecycle.**
   Mjolnir owns run-state, generation, latch, restore. First
   implementation may be an Elixir evaluator of that protocol
   (`Hypervisor` / `Forge.Resource` pattern). A Rust crate is not a
   prerequisite for the first facade.

## Extra, one reader each

- Fable: fail-closed when admit/catalog/`pg_enabled` is down. Sidecar
  growth is **schemas**, not new databases (`bootstrap.ex` is one DB,
  schema-per-role). Syslog negative scan cannot police a guest that
  logs its own nsec. Pubkey distribution is unowned. "No curve math"
  vs envelope verify must be split (verify ≠ custody).
- Sol: admitted token must bind VM + generation + expiry or a
  pre-shutdown admit races `!shutdown`. Current OTP path is at-most-once
  / memory-while-booting (`docs/vm-messaging.md`), not a universal
  queue. PGlite "postgres wire" vs SQL API is underspecified.

## What is solid (both)

Nostr stays the event log. Guests off Distributed Erlang. Admission
before restore. No `if buzz` inside `deliver_message`. Sidecar is not a
tenant hotel. `@base/dev` as human+CI. Permissive vs AGPL repo split.
Opaque nsec. Out-of-scope list is disciplined. Shipped `:never`
finalization already covers the stopped half of I5.

## Steelman (kept)

Wake-on-message is what makes dormancy cheap. If mentions are never
admitted wakes, a Buzz body that must answer chat can never sleep.
That may be correct v1. The spec has to say so.
