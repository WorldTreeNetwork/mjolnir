Rerun of spikes 3 and 7, 2026-11-25. Host firewall path was not used on either machine. No dead-man rollback was armed because nothing was added to a host netns.

Client: openspec/changes/add-turn-service/spikes/turn_client.py. Channel data after ChannelBind (method 0x009, channel 0x4000), not turnutils. Payload prefix TURNRELAY.

## Startup versus the filter — refuted

Morphie unit with ExecStartPre `nft -f` of the uid filter: the beam stayed in erl_child_setup and never bound 3478 (still unbound at 49s). Log from the earlier attempt in the same tree: `Aborting: Cannot create run directory run: permission denied` until `run/` was created and owned by the service user. After that directory existed, a start with the filter still did not bind. A start in the same netns with the table deleted: `Listening on 0.0.0.0:3478` in 2 seconds (22:03:18).

While the filter was loaded, `eturnalctl sessions` as the service user inside the netns printed `Node is not running!`. After `nft delete table inet mjolnir_turn` in that netns only, the same command listed 6 sessions. A tcp/3470 accept is not enough for distribution.

`systemd-nspawn --private-network -D /var/tmp/ubuntu-turn ufw --force enable` printed `Firewall is active and enabled on system startup`. The negative suite was not re-run under a live ufw.
